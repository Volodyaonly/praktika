# Практические работы по Java

Здесь собраны 28 учебных примеров: массивы и циклы, классы и объекты, сортировка,
числовые оболочки, перечисления и интерфейсы. Каждый пример запускается отдельно.
Нужен **JDK 17 или новее**; сторонние библиотеки не используются.

## Быстрый запуск

Открой репозиторий в IntelliJ IDEA, выбери JDK 17 и отметь папку `src` как
**Sources Root**: правой кнопкой → **Mark Directory as → Sources Root**.
После этого открой нужный `Main.java` и нажми зелёную кнопку запуска рядом с `main`.

Для запуска в терминале перейди в корень репозитория:

```bash
javac --release 17 -encoding UTF-8 -d out @sources.txt
java -Dfile.encoding=UTF-8 -cp out ru.mirea.lab2.task01.Main
```

Вторая команда запускает пример с автором книги. Чтобы выбрать другое задание,
замени имя класса после `-cp out` на нужное имя из списка ниже.

Примеры с вводом:

```bash
java -Dfile.encoding=UTF-8 -cp out ru.mirea.lab1.task02.Main
java -Dfile.encoding=UTF-8 -cp out ru.mirea.lab1.task05.Main 13
java -Dfile.encoding=UTF-8 -cp out ru.mirea.lab1.task03.Main первый второй
```

Первая команда просит ввести массив, вторая считает `13!`, третья печатает аргументы.
Если запускаешь факториал без аргумента, программа сама запросит число.

## Как устроен код

- `Main.java` показывает запуск и последовательность действий конкретного задания.
- Модели, например `Author.java`, `Book.java` и `Circle.java`, лежат рядом с его `Main.java`.
- Консольные примеры используют стандартный `Scanner`, массивы и простые циклы.
- `src/ru/mirea/common/movement/` содержит общие классы движения для практик 6 и 7.
  В системе координат этих примеров движение вверх увеличивает `y`.
- `src/ru/mirea/common/Printable.java` — общий интерфейс печати для практик 6 и 7.
- `sources.txt` перечисляет исходники для команды компиляции. При добавлении нового
  `.java`-файла добавь его путь в этот список.

## Что исправлено

- Убраны четыре точные копии решений и пустой `src/Main.java`.
- Закомментированные фрагменты превращены в отдельные программы с точкой входа `main`.
  Одноимённые классы из разных заданий находятся в разных пакетах и не конфликтуют.
- Минимум и максимум массива определяются по его элементам, а сумма хранится в `long`.
- Факториал считается в `BigInteger`, поэтому не переполняется на `13!`.
- Некорректный консольный ввод обрабатывается простыми проверками через `if` и `Scanner`.
- Пустая книжная полка возвращает `null` при поиске книги;
  заполненная полка сохраняет уже добавленные книги и не добавляет лишние.
- Модуль комплексного числа вычисляется через `Math.hypot`, а обработка строк
  учитывает символы вроде эмодзи.

Исходный корневой файл `Практика 1` был копией `Практика 2`.
Настоящие пять примеров для практики 1 взяты из прежнего `src/ru/mirea/lab1/Main.java`.
Все уникальные примеры сохранены; исходные версии доступны в истории Git.

## Проверка

Если установлен Python 3, выполни из корня репозитория:

```bash
python tests/check_examples.py
```

Проверка компилирует все исходники, запускает все 28 примеров и проверяет
обычные и ошибочные варианты ввода. Дополнительные проверки моделей находятся
в `tests/RegressionChecks.java`: пустая полка, отрицательные значения,
факториал, большие комплексные числа и строки с эмодзи.
