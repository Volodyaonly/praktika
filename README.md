# Практические работы по Java — №1 и №2

В репозитории остались только практики №1 и №2: 15 самостоятельных заданий. Нужен JDK 17 или новее.

## Запуск

Открой проект в IntelliJ IDEA, отметь `src` как **Sources Root**, открой нужный `Main.java` и запусти `main`.

```bash
javac --release 17 -encoding UTF-8 -d out @sources.txt
java -Dfile.encoding=UTF-8 -cp out ru.mirea.lab2.task01.Main
```
