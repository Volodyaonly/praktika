# Практическая работа №10

**Задания для показа:** 1, 2 и 3.

Comparator, сортировки студентов по баллу и объединение списков.

Классы Student.java и SortingStudentsByGPA.java являются частью работы, не удаляй их. Comparator прямо требуется условием.

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_10` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab10/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 1: `src/ru/mirea/lab10/task01/Main.java`
- Задание 2: `src/ru/mirea/lab10/task02/Main.java`
- Задание 3: `src/ru/mirea/lab10/task03/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab10/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
