# Практическая работа №11

**Задания для показа:** 1, 2, 3, 4 и 5.

Date, Calendar, форматирование и сравнение списков.

Для задания №3 необходим файл Student.java. В задании №5 ArrayList и LinkedList оставлены по требованию сравнения времени операций.

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_11` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab11/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 1: `src/ru/mirea/lab11/task01/Main.java`
- Задание 2: `src/ru/mirea/lab11/task02/Main.java`
- Задание 3: `src/ru/mirea/lab11/task03/Main.java`
- Задание 4: `src/ru/mirea/lab11/task04/Main.java`
- Задание 5: `src/ru/mirea/lab11/task05/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab11/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
