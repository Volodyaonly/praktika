# Практическая работа №13

**Задания для показа:** 1, 2, 3, 4, 5 и 6.

Методы String, ФИО, адрес, рубашки, номер телефона, цепочка слов.

Классы Person, Address, Shirt и PhoneNumber нужны другим Main.java. В задании №6 при вводе имени файла укажи words.txt (папку практики нужно открыть отдельно, чтобы рабочим каталогом была она).

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_13` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab13/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 1: `src/ru/mirea/lab13/task01/Main.java`
- Задание 2: `src/ru/mirea/lab13/task02/Main.java`
- Задание 3: `src/ru/mirea/lab13/task03/Main.java`
- Задание 4: `src/ru/mirea/lab13/task04/Main.java`
- Задание 5: `src/ru/mirea/lab13/task05/Main.java`
- Задание 6: `src/ru/mirea/lab13/task06/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab13/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
