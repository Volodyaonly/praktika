# Практическая работа №14

**Задания для показа:** 1–9.

Регулярные выражения, проверка дат и паролей, Filter, подсчёт букв.

В задании №8 нужен интерфейс Filter.java. В методичке №14 есть противоречия в примерах: сверяй с описанными требованиями, они отмечены в корневом README.

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_14` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab14/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 1: `src/ru/mirea/lab14/task01/Main.java`
- Задание 2: `src/ru/mirea/lab14/task02/Main.java`
- Задание 3: `src/ru/mirea/lab14/task03/Main.java`
- Задание 4: `src/ru/mirea/lab14/task04/Main.java`
- Задание 5: `src/ru/mirea/lab14/task05/Main.java`
- Задание 6: `src/ru/mirea/lab14/task06/Main.java`
- Задание 7: `src/ru/mirea/lab14/task07/Main.java`
- Задание 8: `src/ru/mirea/lab14/task08/Main.java`
- Задание 9: `src/ru/mirea/lab14/task09/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab14/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
