# Готовые папки для защиты практических работ Java

Каждая практика лежит в **отдельной папке**, с собственными файлами и классами. Открывай нужную папку в IntelliJ IDEA как отдельный проект, а каталог `src` помечай **Mark Directory as → Sources Root**.

| Работа | Папка | Какие задания внутри |
|---|---|---|
| №8, рекурсия | [praktika_08](praktika_08/) | 16 и 17 (вариант №16) |
| №9, сортировки | [praktika_09](praktika_09/) | 1, 2, 3, 4 |
| №10, Comparator | [praktika_10](praktika_10/) | 1, 2, 3 |
| №11, дата и время | [praktika_11](praktika_11/) | 1–5 |
| №13, обработка строк | [praktika_13](praktika_13/) | 1–6 |
| №14, регулярные выражения | [praktika_14](praktika_14/) | 1–9 |

**Обрати внимание на №8.** В методичке написано выполнять **3–5 заданий начиная с номера в журнале**, а при варианте №16 до конца списка остаются только №16 и №17. Правило перехода к №1 в методичке не указано. Здесь оставлены **два точно подходящих задания**; третье (и, возможно, остальные) надо согласовать с преподавателем. Поэтому №8 пока не отмечаем как полностью готовую к сдаче.

Внутри каждой папки `src/ru/mirea/labXX/` есть `taskXX/Main.java`; рядом лежат необходимые классы (например, `Student.java`). Запускай нужный `Main.java` зелёной кнопкой в IDEA.

**Оригинальные программы остались** в корневом `src/`: папка `NA_ZASHCHITU` содержит отдельные копии для защиты и не влияет на существующие тесты. После изменений в оригиналах копии нужно синхронизировать.

Код учебный. `Comparator` в №9–10, `Pattern/Matcher` в №14, `ArrayList/LinkedList` в №11.5 оставлены только потому, что они предусмотрены соответствующими заданиями.

Чтобы проверить независимую компиляцию папок: `python tests/check_defense_folders.py` из корня репозитория.
