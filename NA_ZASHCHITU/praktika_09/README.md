# Практическая работа №9

**Задания для показа:** 1, 2, 3 и 4.

Сортировки: вставками, быстрая, слиянием; собственный Comparable.

Файлы Student.java и SortingStudentsByGPA.java общие для заданий. Comparable изучается в самой методичке.

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_09` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab9/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 1: `src/ru/mirea/lab9/task01/Main.java`
- Задание 2: `src/ru/mirea/lab9/task02/Main.java`
- Задание 3: `src/ru/mirea/lab9/task03/Main.java`
- Задание 4: `src/ru/mirea/lab9/task04/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab9/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
