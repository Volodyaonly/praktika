# Практическая работа №8

**Задания для показа: 16, 17 и 1 (вариант №16).**

По методичке требуется выполнить 3–5 заданий, начиная с номера в журнале. После №17 для третьего задания выбран №1. Если преподаватель задаст другой порядок перехода, его следует уточнить.

- №16 — количество элементов, равных максимальному.
- №17 — максимум последовательности.
- №1 — треугольная последовательность: одно использование цикла for разрешено текстом методички.

## Запуск

1. Открой `NA_ZASHCHITU/praktika_08` в IntelliJ IDEA как отдельный проект.
2. Отметь `src` как **Sources Root**.
3. Запусти нужный класс:
   - `src/ru/mirea/lab8/task16/Main.java`
   - `src/ru/mirea/lab8/task17/Main.java`
   - `src/ru/mirea/lab8/task01/Main.java`
