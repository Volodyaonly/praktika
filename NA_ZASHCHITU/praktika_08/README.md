# Практическая работа №8

**Задания для показа:** 16 и 17.

Рекурсия. Вариант №16.

По методичке нужны 3–5 последовательных заданий с номера в журнале. После №17 методичка не определяет порядок выбора, поэтому здесь пока только №16 и №17. Третье задание нужно уточнить у преподавателя.

## Как запустить

1. Открой `NA_ZASHCHITU/praktika_08` в IntelliJ IDEA как отдельный проект.
2. Пометь папку `src` как **Sources Root**.
3. Открой соответствующий `src/ru/mirea/lab8/taskXX/Main.java`.
4. Нажми ▶ рядом с `main`, покажи вывод и объясни основной алгоритм.

Путь к классам по заданиям:
- Задание 16: `src/ru/mirea/lab8/task16/Main.java`
- Задание 17: `src/ru/mirea/lab8/task17/Main.java`

Можно также скомпилировать всю практику: `javac -encoding UTF-8 -d out src/ru/mirea/lab8/**/*.java` (в Windows удобнее запускать через IDEA). Это **отдельная копия**, исходники в главном `src` не менялись.
